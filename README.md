# Site Doces da Vika

Landing page estática para apresentar doces personalizados da Viviane Beiruth.

## Tecnologia

- HTML
- CSS
- JavaScript puro

Não usa Node.js, React, Next.js, pnpm ou etapa de build.

## Como abrir

Abra `index.html` no navegador.

Opcional, para servir localmente:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Estrutura

```text
index.html       Página principal
styles.css       Estilos da página
script.js        Animações leves e ano do rodapé
public/          Imagens e ícones
```
